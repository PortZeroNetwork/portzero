# Target audience: users

People who **use** the Port Zero client on their own machine: developers who
install `portzero`, run the daemon, and expose local processes or Docker
containers as Local (`*.portzero.local`) or Cloud (`*.tunnel.portzero.cloud`)
tunnels.

Assume familiarity with a terminal and everyday developer tooling, but **not**
with this repository's internals. Prefer plain, user-facing wording
(`process`, `Docker container`, `Local tunnel`, `Cloud tunnel`) over code terms
like `service`.

> **Canonical published docs live elsewhere.** The public, user-facing product
> documentation is served at [portzero.net/docs](https://portzero.net/docs),
> sourced from the `portzero-cloud` repo
> (`cloud/landing/blog/src/data/docs/`). The pages under `docs/users/` here are
> the in-repo copies for docs that describe the behavior of *this* client
> binary (for example, the privacy notice). When you change a user-facing
> behavior here, mirror the change on portzero.net/docs.
